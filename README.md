# KUWADRO

Minimalist fashion e-commerce website concept built with HTML, CSS, and JavaScript.

## Features

- Product catalog
- Product details
- Shopping cart
- Checkout UI
- Lookbook
- Responsive design
- Email signup
- Custom SVG visuals and animations

## Tech Stack

- HTML5
- CSS3
- JavaScript
- SVG
- Google Fonts
- Netlify Functions

## Collection

- Mass Overcoat
- Void Jacket
- Column Trousers
- Slab Tee
- Drape Vest
- Shell Pant

## Notes

This is a frontend prototype. Payment processing and orders are simulated.
